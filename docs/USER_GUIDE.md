# BCI-Desk 使用说明书

**版本**：0.1.0  
**适用硬件**：OpenBCI Cyton + Daisy（16 通道 EEG）  
**软件定位**：面向研究 / 教育的本地脑机接口（BCI）工作台 — **非医疗器械**

**开发目的**：针对 OpenBCI 系列硬件搭建基础平台，完善从连接、质检、采集到基础分析与落盘的基本处理 / 使用流程，便于在此之上做更深度的个性化开发与科研、教学内容扩展。本软件提供可运行的基线，而不是封闭的最终产品。

本说明书结合软件功能、硬件配置，以及实际操作记录（115200 默认档 / 921600 高速档）整理。配图来自操作记录 Word，统一存放在：

  921600/   # 高速档操作截图 01.png … 13.png

## 1. 重要声明

- BCI-Desk **仅供科研与教学**，不得用于临床诊断、治疗决策或急救。
- 软件按「现状」提供，使用脑电硬件与采集分析的风险由使用者自行承担。
- 完整免责见仓库根目录 [`NOTICE.md`](../NOTICE.md)；开源许可为 MIT（[`LICENSE`](../LICENSE)）。

## 2. 软件能做什么

本仓库把 OpenBCI 侧「能连上、能看信号、能按范式采、能做基础分析」这条主链路先搭稳；模块如下，可按科研 / 教学需要继续改与扩展。

| 模块 | 作用 |
|------|------|
| **双通道对比** | 实时时域波形 + FFT 频谱，确认信号是否正常 |
| **阻抗检测** | 16 通道电极接触质量（kΩ） |
| **专注指标** | β/(α×4)×100 专注指数及对比指标 |
| **实时佩戴检测** | 16 通道 SQI / 拓扑示意图 |
| **信号校验** | 固定时长录制，检查落盘幅值、主频是否符合脑电要求 |
| **采集范式** | 手指 / 手形运动执行（ME）打标签落盘（训练集 / 测试集） |
| **ERD/ERS 检测** | 左右手握拳范式，在线 Mu / Beta 时频分析 |

底层逻辑在 `bci_desk/`（无 PyTorch）；EEGNet 训练在独立目录 `training/`（可拷到服务器运行）。

## 3. 环境安装与启动

### 3.1 要求

- **Python** 3.10+（建议）
- **操作系统**：Windows / macOS / Linux（开发与实测以 Windows 为主）
- **硬件**：OpenBCI Cyton + Daisy，PC 端 USB 串口（蓝牙适配器）

### 3.2 安装依赖

```bash
# 建议使用独立 conda / venv
pip install -r requirements.txt
```

训练端另需：

```bash
cd training
pip install -r requirements.txt
```

### 3.3 启动

```bash
python main.py
```

程序会记住本机：串口、波特率、「应用硬件设置」、带通/陷波、范式选择等。

## 5. 硬件与采样率（必读）

### 5.1 两个关键概念

| 档位 | 波特率 | 板卡 `~` 命令 | 帧采样率 | **通道采样率** | 驱动 |
|------|--------|---------------|----------|----------------|------|
| 默认 | **115200** | `~6` | 250 Hz | **125 Hz** | BrainFlow |
| 高速 | **921600** | `~4` | 1000 Hz | **500 Hz** | pyserial 直连 |

> 界面实测 / 落盘 meta 里的 `sample_rate` 是 **通道采样率**（125 或 500），不是板卡回显的 250 / 1000。

### 5.2 连接失败最常见原因

**PC 软件波特率 ≠ 硬件（SW4 + 适配器）波特率。**

### 5.3 Profile A：115200 · 通道 125 Hz

1. 采集板 **SW4** → **115200**，完成上电与适配器配置。  
2. 串口工具 115200，发 `AT` → `OK`；发 `~6` → 帧 250 Hz。  
3. BCI-Desk 选 **115200** → 连接 → 开始采集。  
4. （建议）**采样配置…** 实测通道率，期望约 **115–135 Hz**。

### 5.4 Profile B：921600 · 通道 500 Hz（配图）

可用外部软件先确认佩戴与注膏后通道变好：

![佩戴注膏后通道变好](images/921600/01.png)

![明显眨眼伪迹（外部软件）](images/921600/02.png)

*图：可观测到明显眨眼伪迹。*

配置硬件参数、等待通道接通：

![配置硬件参数](images/921600/03.png)

*图：配置硬件参数。*

![通道接通中](images/921600/04.png)

*图：通道接通中。*

![可以看到眨眼伪迹](images/921600/05.png)

*图：接通后可见眨眼伪迹。*

## 6. 推荐完整操作流程

```
硬件档位核对（SW4 + AT + ~命令）
        ↓
BCI-Desk 选对波特率 → 连接 → 开始采集
        ↓
双通道对比：波形 / 眨眼伪迹
        ↓
阻抗检测：多数通道 ≤ 100 kΩ
        ↓
（可选）佩戴检测 / 专注指标
        ↓
（推荐）信号校验：幅值、主频达标
        ↓
采集范式：训练采集 或 测试集采集
        ↓
（可选）ERD/ERS
```

## 8. 双通道对比

用于查看任意两路 EEG 的时域与频谱。

### 8.1 已知信号自检（115200）

![3 通道正弦波自检](images/115200/06.png)

*图：给了 3 个通道正弦波（100 µVpp，5 Hz）。*

### 8.2 真人信号（921600）

![采集到的脑电波形](images/921600/11.png)

*图：可看到采集到的脑电波形。*

![明显眨眼伪迹](images/921600/12.png)

![眨眼伪迹（续）](images/921600/13.png)

*图：可看到明显的眨眼伪迹。*

### 8.3 使用建议

1. **开始采集** 后进入本页。  
2. 安静基线 + 故意眨眼，确认通路大致正常。  
3. 调节顶部带通 / 陷波 / FFT 最大频率观察效果。  
4. 虚拟调试端口仅动画、**不落盘**。

## 9. 阻抗检测

正式采集前建议多数通道 **≤ 100 kΩ**。

| 阻抗 | 质量 |
|------|------|
| ≤ 10 kΩ | 极好 |
| ≤ 50 kΩ | 良好 |
| ≤ 100 kΩ | 可接受（合格上限） |
| ≤ 200 kΩ | 偏高 |
| > 200 kΩ | 差 / 未接好 |

![阻抗检测界面](images/115200/07.png)

![阻抗检测（续）](images/115200/08.png)

*图：阻抗检测。*

**开始检测 = 打开电流源；停止检测 = 关闭电流源：**

![电流源开闭说明](images/115200/09.png)

*图：开始检测打开电流源；停止检测关闭电流源。*

注意：与部分任务互斥；通道接近满量程（饱和）时阻抗不可信。

## 10. 专注指标

基于 **CH1 + CH2**：约 1–28 Hz 带通 + 陷波，核心为 **β/(α×4)×100** 专注指数（研究用启发式，非临床评估）。

![专注检测界面](images/115200/10.png)

*图：专注检测界面。*

![专注指标数据](images/115200/11.png)

*图：专注指标数据。*

操作：**开始采集** → **开始专注力检测** → 观察指数与曲线 → 停止。

## 11. 实时佩戴检测

16 通道短时波形 + 拓扑 / 数值列表；每通道 SQI（0–100）。常见：SQI 较高（如 ≥ 60）偏良好。

![实时佩戴检测](images/115200/12.png)

*图：实时佩戴检测。*

结合注膏与双通道眨眼伪迹，可快速判断哪些位点需补膏或重贴。

## 12. 信号校验

正式打标签采集前，用固定时长录制确认 **落盘** 数据的幅值、主频是否合格（不只看实时波形）。

![信号校验](images/115200/13.png)

*图：采集范式开始之前，通过信号校验检测落盘数据是否符合脑电要求（幅值、主频）。*

数据默认写在 `data/validation/`；落盘前应用顶部全局带通/陷波。

## 13. 采集范式

### 13.1 选择范式

![采集范式选择](images/115200/14.png)

*图：采集范式选择。*

| 范式 id | 界面名称 | 类别 |
|---------|----------|------|
| `finger_2` | 两指运动执行（拇指/小指） | THUMB / PINKY |
| `finger_3` | 三指运动执行（拇指/食指/小指） | THUMB / INDEX / PINKY |
| `finger_4` | 四指运动执行（全四指） | THUMB / INDEX / MIDDLE / PINKY |
| `hand_2class` | 手形二分类（握拳/放松） | FIST / RELAX |
| `hand_3class` | 手形三分类（握拳/放松/张掌） | FIST / RELAX / PALM |

**不同范式分别采集、分别训练。**

### 13.2 训练采集 vs 测试集

| 模式 | 说明 | 落盘 |
|------|------|------|
| **训练采集** | 完整 Segment（手指默认约 3×300 试次） | `data/acquisition/<id>/` |
| **测试集采集** | 缩短版（约 1×20 试次） | `data/test/<id>/` |

测试集供服务器 `evaluate.py`，**不是**本机实时分类。

### 13.6 任务要点

- **手指 ME**：双手放松；出现指号时屈伸该指 **1 次**。  
- **手形 ME**：按提示握拳 / 放松 / 张掌并保持；二分类试次间通常无「+」休息。  
- 尽量不眨眼、不咬牙、不晃头。

## 14. ERD/ERS 检测

左右手真实握拳；在线看 Mu / Beta 的 ERD（负值=抑制）与 ERS。

单试次：Baseline 2 s → Ready 1 s → 握拳 4 s → Relax 2 s → ITI 1 s。默认每侧约 40 试次。虚拟端口不支持本页。

![ERD/ERS 检测](images/115200/20.png)

*图：ERD、ERS 检测。*

数据写入 `data/erders/`。

## 18. 常见问题排查

| 现象 | 可能原因 | 处理 |
|------|----------|------|
| 连接失败 | 波特率与 SW4/适配器不一致 | 核对 115200/921600；串口助手验 `AT` |
| 无波形 | 未开始采集；滤波预热中；电极差 | 开始采集；等预热；查阻抗 |
| 采样率偏差大 | `~` 命令或档位混用 | `~6`↔125 Hz；`~4`↔500 Hz |
| 阻抗全差 | 缺膏 / 参考电极 / 开路 | 重贴注膏；看是否饱和 |
| 采集卡住 | 等待空格 | 按空格继续 |
| 采样配置打不开 | 其它任务进行中 | 先停止阻抗/范式/ERD/校验 |

日志：`data/logs/bci_desk_YYYYMMDD.log`。
